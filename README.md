# DO FIVE
Do Five is a daily habit tracker that helps you work towards your goals. It is built on one simple idea, that is breaking down your aspirations into a quick 5 minute challenge makes it easy to do every day, and gives you no excuse to avoid it (it's only 5 minutes!).

Check it out at <a href="https://dofive.netlify.app">dofive.netlify.app</a>!

## Features
- Make your challenge
  - 5 premade challenges to choose from
  - Option to make your own custom challenge
- Do your challenge
  - Embedded YouTube videos make it easy to follow along
  - Built in 5-minute timer
- Track your streak
  - Each day you complete your challenge updates your streak
  - Missing a day resets it to 0
- Lightweight and easy to use
  - No need to sign in, progress is saved locally on your browser
  - Mobile-friendly

## Deployment
The website is continuously deployed through Netlify.
- Any push to the main branch will trigger Netlify to build and deploy it
- This allows for quick bug fixes, and makes it easy to add new features
